# Credits & Attribution

This plugin is built on the shoulders of the open source community. We curate — we don't rebuild.

## MCP Servers

- **meta-ads-mcp** by [brijr](https://github.com/brijr/meta-mcp) (MIT)
  44-tool Meta Ads MCP server. Local stdio execution, comprehensive API coverage. Primary MCP for this plugin.

## Evaluated Alternatives (not used, but documented)

- **pipeboard-co/meta-ads-mcp** by [Pipeboard](https://github.com/pipeboard-co/meta-ads-mcp) (563 stars)
  SSE-based remote alternative. Documented as option for teams preferring managed infrastructure.

## Companion Tools (referenced, not bundled)

- **claude-ads** by [AgriciDaniel](https://github.com/AgriciDaniel/claude-ads) (652 stars)
  186 cross-platform audit checks including 46 Meta checks. We reference it for quarterly deep audits — we don't rebuild it.
- **meta-ads-analyzer** by [mathiaschu](https://github.com/mathiaschu/meta-ads-analyzer) (215 stars)
  Breakdown Effect analysis. Inspired our audience-analyzer skill's breakdown approach.
- **facebook-ads-library-mcp** by [trypeggy](https://github.com/trypeggy/facebook-ads-library-mcp)
  Ad Library MCP server. Referenced as optional companion for competitor-research skill.

## Design Influences

- **marketingskills** by [coreyhaines31](https://github.com/coreyhaines31/marketingskills) (10,890 stars)
  Proved the skills-as-markdown-files pattern works at scale.
- **talknerdytome-labs/claude-agents** — Multi-competitor benchmarking agent pattern.
  Inspired our competitor-scout subagent architecture.

## Standards

- [SKILL.md open standard](https://skills.sh) — the skill format this plugin uses
- [Model Context Protocol](https://modelcontextprotocol.io) by Anthropic — the MCP specification

If you built something we reference or were inspired by, and we missed you — open an issue. We want to get this right.
