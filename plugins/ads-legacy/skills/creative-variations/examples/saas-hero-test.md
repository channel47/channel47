# Example: SaaS Hero Image Creative Test

Demonstrates the creative variations workflow for a B2B SaaS product's LinkedIn and display ads.

---

## Context

**Product:** Project management software
**Winning Creative:** Dashboard screenshot with headline "Finally, Projects That Ship On Time"
**Performance:** 0.8% CTR on LinkedIn (above 0.5% benchmark)
**Goal:** Scale with fresh creatives while maintaining performance

---

## Phase 1: Creative Analysis

### Why It Works

The creative combines proof (dashboard screenshot) with outcome promise (on-time delivery). The headline addresses a specific pain point every PM feels. The screenshot establishes credibility—this is a real product that does what it claims.

### Psychological Triggers Identified

| Trigger | Implementation |
|---------|----------------|
| Pain Point Address | "Finally" implies long struggle, relief ahead |
| Specificity | "Ship On Time" is concrete, measurable outcome |
| Authority/Proof | Dashboard screenshot = real working product |
| Transformation | Implies shift from chaos to control |
| Identity | "Projects" speaks directly to PM role |

### Elements to Preserve (Control Constants)

- Dashboard screenshot (the proof element)
- "Finally" opener (pain acknowledgment)
- Professional B2B aesthetic
- Clean typography
- Blue/professional color scheme

### High-Potential Test Variables

1. **Headline pain point** - Test different PM frustrations
2. **Screenshot focus** - Test different dashboard views
3. **Human element** - Test with/without person
4. **Social proof** - Test adding customer logo or metric

## Phase 2: Variant Strategy

| Variant | Change | Hypothesis |

### Testing Recommendations

**Platform:** LinkedIn (primary), Google Display (secondary)
**Budget:**
- LinkedIn: $100/variant minimum (higher CPM)
- GDN: $50/variant
**Primary Metric:** CTR
**Secondary Metric:** Demo requests / Sign-ups
**Minimum Runtime:** 10-14 days (B2B has longer consideration)

### B2B-Specific Considerations

- LinkedIn audience is smaller—tests take longer to reach significance
- Day-of-week effects are strong (weekday vs. weekend performance varies)
- Consider testing by job title targeting separately
- Demo request quality matters more than volume

### Decision Framework

| If Winner | Implication | Next Test |
|-----------|-------------|-----------|
| V1 (Time-saving) | Efficiency message resonates | Test other time-based benefits |
| V2 (Human + testimonial) | Trust/relatability matters | Test different testimonial formats |
| V3 (Enterprise logos) | Social proof critical | Test specific vs. generic logos |
| V4 (Stop chasing) | Pain agitation works | Test other pain points |
| Control | Original positioning is strong | Test completely different approaches |

## Notes on B2B Creative Testing

### Longer Test Cycles

B2B audiences are smaller and more targeted. Plan for:
- 2-3x longer test duration vs. B2C
- Lower absolute numbers but still significant
- Higher quality signal from demo/signup actions

### Consider Funnel Stage

Different creatives win at different stages:
- **Top of funnel:** Pain agitation, curiosity
- **Mid funnel:** Proof, features, comparison
- **Bottom funnel:** Urgency, risk removal, social proof

### Job Title Testing

If possible, segment tests by role:
- ICs (Individual Contributors) respond to productivity gains
- Managers respond to visibility/control
- Executives respond to business outcomes/ROI
