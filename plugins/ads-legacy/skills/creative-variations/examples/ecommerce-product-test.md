# Example: E-commerce Product Creative Test

Demonstrates the creative variations workflow for a supplement brand's Facebook ad.

---

## Context

**Product:** Daily vitamin subscription
**Winning Creative:** Product bottle on gradient background with headline "Feel Better Every Day"
**Performance:** 2.4% CTR (above 1.8% benchmark)
**Goal:** Find variations that can beat the control

---

## Phase 1: Creative Analysis

### Why It Works

The creative succeeds through simplicity and aspiration. The clean gradient background creates pattern interrupt in busy feeds, while the transformation-focused headline ("Feel Better") speaks to desired outcome rather than product features.

### Psychological Triggers Identified

| Trigger | Implementation |
|---------|----------------|
| Pattern Interrupt | Gradient background stands out vs. typical lifestyle imagery |
| Transformation Promise | "Feel Better" implies change from current state |
| Simplicity | Single product focus, minimal visual complexity |
| Aspiration | "Every Day" creates vision of consistent wellness |

### Elements to Preserve (Control Constants)

- Product bottle appearance and position (center)
- Gradient background style (not the specific colors)
- Clean, minimal aesthetic
- Headline font style and size
- Logo position (bottom right)

### High-Potential Test Variables

1. **Headline angle** - Test benefit specificity vs. emotional appeal
2. **Background color** - Test warm vs. cool gradient
3. **Social proof addition** - Test with/without trust element

---

## Phase 2: Variant Strategy

Following the 1-2 element rule, creating 4 variants:

| Variant | Change | Hypothesis |
|---------|--------|------------|
| V1 | Headline: "Feel Better" → "More Energy in 7 Days" | Specificity increases believability |
| V2 | Background: Blue gradient → Warm orange gradient | Warm colors increase engagement |
| V3 | Add: Star rating badge (4.8/5) | Social proof increases trust |
| V4 | Headline: "Feel Better" → "Join 50,000 Feeling Better" | Social proof in headline combines triggers |

## Phase 4: Deliverables

### Files Generated

- `control-feel-better.png`
- `variant-1-energy-7-days.png`
- `variant-2-warm-gradient.png`
- `variant-3-star-rating.png`
- `variant-4-join-50k.png`

### Testing Recommendations

**Platform:** Facebook/Instagram
**Budget:** Equal split across all 5 (control + 4 variants)
**Minimum Budget:** $50/variant for statistical validity
**Primary Metric:** CTR (click-through rate)
**Secondary Metric:** Cost per initiate checkout
**Minimum Runtime:** 7 days

### Decision Framework

| If Winner | Implication | Next Test |
|-----------|-------------|-----------|
| V1 (Specific benefit) | Specificity resonates | Test different timeframes ("3 days" vs "14 days") |
| V2 (Warm colors) | Color psychology matters | Test other warm variations |
| V3 (Rating badge) | Trust signals help | Test other proof types (testimonial, user count) |
| V4 (Social headline) | Combined triggers win | Test different social proof numbers |
| Control | Original instinct correct | Test completely different angles |
