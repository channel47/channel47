# Microsoft Advertising UI Paths

Step-by-step navigation paths for actions recommended by microsoft-ads plugin skills.

## Campaign Settings

### Disable MSAN (Microsoft Audience Network)
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Ad distribution > uncheck "Microsoft Audience Network" > Save

### Disable search partners
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Ad distribution > uncheck "Include search partners" > Save

### Set physical location targeting
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Locations > Location options > select "People in your targeted locations" > Save

### Set ad scheduling
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Ad scheduling > + Add schedule > set days and hours > Save

### Adjust campaign budget
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Budget > enter new daily budget > Save

### Change bid strategy
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Bid strategy > select strategy > Save

### Pause a campaign
Microsoft Advertising > Campaigns > check campaign > Edit > Pause

## Keywords

### Pause a keyword
Microsoft Advertising > Campaigns > [Campaign Name] > Ad groups > [Ad Group Name] > Keywords > check keyword > Edit > Pause

### Change keyword bid
Microsoft Advertising > Campaigns > [Campaign Name] > Ad groups > [Ad Group Name] > Keywords > click bid column > enter new bid > Save

### Change keyword match type
Microsoft Advertising > Campaigns > [Campaign Name] > Ad groups > [Ad Group Name] > Keywords > check keyword > Edit > Change match type

## Negative Keywords

### Add campaign-level negatives
Microsoft Advertising > Campaigns > [Campaign Name] > Keywords > Negative keywords > + Add negative keywords > paste keywords > Save

### Add ad-group-level negatives
Microsoft Advertising > Campaigns > [Campaign Name] > Ad groups > [Ad Group Name] > Keywords > Negative keywords > + > paste keywords > Save

### Create shared negative keyword list
Microsoft Advertising > Tools > Shared library > Negative keyword lists > + Create > name list > add keywords > Save

### Apply shared list to campaigns
Microsoft Advertising > Tools > Shared library > Negative keyword lists > select list > Apply to campaigns > check campaigns > Save

## Import

### Review auto-import schedule
Microsoft Advertising > Import > Google Ads > Schedule and settings > review or disable auto-import

### Run manual import
Microsoft Advertising > Import > Google Ads > Import now > review changes > Import

### Change import settings
Microsoft Advertising > Import > Google Ads > Choose what to import > review each category > Save

## Placements & Publisher URLs

### View publisher URL report
Microsoft Advertising > Reports > Standard reports > Performance > Publisher URL performance > set date range > Run

### Add website exclusions
Microsoft Advertising > Campaigns > [Campaign Name] > Settings > Website exclusions > + Add > paste URLs > Save

### Add account-level website exclusions
Microsoft Advertising > Tools > Shared library > Website exclusion lists > + Create > name list > add URLs > Save

## Ads & Extensions

### Edit RSA headlines/descriptions
Microsoft Advertising > Campaigns > [Campaign Name] > Ad groups > [Ad Group Name] > Ads > click ad > Edit > modify headlines/descriptions > Save

### Add sitelinks
Microsoft Advertising > Ads & extensions > Extensions > Sitelink extensions > + Add > fill in details > Save

### Add callouts
Microsoft Advertising > Ads & extensions > Extensions > Callout extensions > + Add > fill in details > Save

## Conversion Tracking

### Check UET tag status
Microsoft Advertising > Tools > UET tags > verify tag status (active/inactive)

### Create conversion goal
Microsoft Advertising > Tools > Conversion goals > + Create > configure goal > Save

## Reports

### View search terms report
Microsoft Advertising > Reports > Standard reports > Performance > Search term > set date range > Run

### View invalid clicks report
Microsoft Advertising > Reports > Standard reports > Performance > check "Invalid clicks" column

### View campaign performance
Microsoft Advertising > Reports > Standard reports > Performance > Campaign > set date range > Run
