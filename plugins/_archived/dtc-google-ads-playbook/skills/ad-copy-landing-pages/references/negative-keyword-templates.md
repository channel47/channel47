## Match Type Strategy

### When to Use Each Match Type

| Match Type | Use For | Example |
|------------|---------|---------|
| Broad | Competitor names (block all variations) | `Mounjaro` |
| Phrase | Multi-word concepts to block | `"free sample"` |
| Exact | Specific queries to redirect or block | `[tirzepatide side effects]` |

### Negative Keyword List Organization

Create these shared lists that apply across campaigns:

1. **Competitor Brands** — all competitor names, broad match
2. **Brand Navigation** — {brand} login/account/cancel, broad match
3. **Low Intent / Research** — informational queries, exact match
4. **Product Cannibalization** — terms to funnel to specific campaigns, exact match
5. **Jobs & Careers** — job-seeking queries, broad match

### Review Cadence

| Action | Frequency | Source |
|--------|-----------|--------|
| Add new negatives from search terms | Weekly | Search Terms Report |
| Review negative keyword lists for over-blocking | Monthly | Negative Keyword Report |
| Update competitor list | Monthly | Auction Insights Report |
| Audit exact match negatives | Quarterly | Campaign performance data |
