# Meta Ads Manager UI Paths

Step-by-step navigation paths for actions recommended by meta-ads plugin skills.

## Campaigns

### Pause a campaign
Meta Ads Manager > Campaigns tab > check campaign > toggle Status to Off

### Adjust campaign budget
Meta Ads Manager > Campaigns tab > [Campaign Name] > click budget column > enter new budget > Save

### Change campaign objective
Note: Campaign objective cannot be changed after creation. Create a new campaign with the desired objective.

### Set campaign spending limit
Meta Ads Manager > Campaigns tab > [Campaign Name] > Edit > Campaign spending limit > enter amount > Save

## Ad Sets

### Pause an ad set
Meta Ads Manager > Ad sets tab > check ad set > toggle Status to Off

### Adjust ad set budget
Meta Ads Manager > Ad sets tab > [Ad Set Name] > click budget column > enter new budget > Save

### Change audience targeting
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Edit > Audience section > modify targeting > Save

### Exclude Audience Network placement
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Edit > Placements > Manual placements > uncheck "Audience Network" > Save

### Set frequency cap (Reach campaigns only)
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Edit > Optimization & Delivery > Frequency cap > set cap > Save

### Add custom audience exclusion
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Edit > Audience > Exclude > Custom Audiences > select audience > Save

### Check audience overlap
Meta Ads Manager > Audiences (left nav) > check 2+ audiences > Actions > Show audience overlap

## Ads

### Pause an ad
Meta Ads Manager > Ads tab > check ad > toggle Status to Off

### Duplicate an ad (for creative refresh)
Meta Ads Manager > Ads tab > check ad > Duplicate > modify creative > Publish

### Edit ad creative
Meta Ads Manager > Ads tab > [Ad Name] > Edit > modify creative elements > Publish

### Preview an ad
Meta Ads Manager > Ads tab > [Ad Name] > Preview > select placement to preview

## Audiences

### Create custom audience
Meta Ads Manager > Audiences (left nav) > Create audience > Custom audience > select source > configure > Create

### Create lookalike audience
Meta Ads Manager > Audiences (left nav) > Create audience > Lookalike audience > select source > choose location and size > Create

### View audience size estimate
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Edit > Audience > view Estimated audience size in right panel

## Conversion Tracking

### Check pixel status
Meta Events Manager > Data sources > [Pixel Name] > Overview > verify "Active" status

### View conversion events
Meta Events Manager > Data sources > [Pixel Name] > Test events or Overview > check event reception

### Configure attribution window
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Edit > Optimization & Delivery > Attribution setting > select window

## Reporting & Breakdowns

### View performance by placement
Meta Ads Manager > Campaigns/Ad sets/Ads tab > Breakdown > By delivery > Placement

### View performance by device
Meta Ads Manager > Campaigns/Ad sets/Ads tab > Breakdown > By delivery > Device

### View performance by age/gender
Meta Ads Manager > Campaigns/Ad sets/Ads tab > Breakdown > By delivery > Age / Gender

### View delivery insights
Meta Ads Manager > Ad sets tab > [Ad Set Name] > Inspect (chart icon) > view auction overlap, audience saturation

### Export performance data
Meta Ads Manager > select entities > Export > select format (CSV/Excel) > Export

## Ad Library (Competitor Research)

### Search competitor ads
Meta Ad Library > facebook.com/ads/library > select country > select ad category > search by advertiser name

### Filter active ads
Meta Ad Library > search results > filter by "Active" status > sort by "Newest"

## Account Settings

### View account spending limit
Meta Ads Manager > Billing (left nav) > Payment settings > Account spending limit

### Check ad account status
Meta Business Settings > Ad accounts > select account > verify status
