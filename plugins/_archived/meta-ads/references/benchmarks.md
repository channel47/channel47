# Meta Ads Benchmarks (2026)

Use benchmarks as context, not hard policy. Prefer account history when available.

## CPM by objective

| Objective | Typical CPM Range | Notes |
|-----------|------------------|-------|
| Conversions | $8 - $25 | Varies heavily by vertical and audience size |
| Traffic | $4 - $12 | Lower funnel = higher CPM |
| Awareness/Reach | $2 - $8 | Broad targeting = lower CPM |
| Lead Generation | $6 - $20 | Form quality impacts cost |
| App Installs | $5 - $15 | Seasonal variation significant |
| Video Views | $3 - $10 | ThruPlay vs 2-second views differ |

## CTR by placement

| Placement | Typical CTR Range |

| Instagram Stories | 0.4% - 1.5% |
| Instagram Reels | 0.3% - 1.0% |
| Audience Network | 0.2% - 0.8% |
| Right Column | 0.1% - 0.5% |

## Video metrics

| Metric | Benchmark |
|--------|-----------|
| ThruPlay rate (15s) | 15% - 35% |
| 3-second video view rate | 40% - 70% |
| Average watch time | 3 - 8 seconds |
| Hook rate (first 3s retention) | > 30% is good, > 50% is excellent |
| Hold rate (watch > 50%) | > 15% is good, > 25% is excellent |

## Frequency impact on performance

| Frequency Range | Expected Performance Impact |
|-----------------|---------------------------|
| 1.0 - 2.0 | Optimal — fresh audience |
| 2.0 - 3.0 | Acceptable — watch CTR trends |
| 3.0 - 5.0 | Degrading — plan creative refresh |
| 5.0 - 7.0 | Significant fatigue — rotate immediately |
| 7.0+ | Severe fatigue — pause and rebuild |

## Ad strength indicators

| Signal | Good | Needs Work |
|--------|------|------------|
| Ad relevance diagnostics | Above Average | Below Average |
| Quality ranking | Above Average | Below Average |
| Engagement rate ranking | Above Average | Below Average |
| Conversion rate ranking | Above Average | Below Average |

## ROAS benchmarks

| Performance vs Target ROAS | Status |
|---------------------------|--------|
| >= 120% of target | Efficient — scale candidate |
| 100% - 120% of target | On track |
| 80% - 100% of target | Watch — optimize creative/audience |
| < 80% of target | Investigate / action |

## Notes

- Vertical variation is large; always compare against account baseline first.
- Benchmarks are directional and should be called out as estimates.
- Meta's algorithm changes frequently; benchmarks may shift quarterly.
- iOS 14.5+ attribution changes affect reported conversion metrics. Consider longer attribution windows.
