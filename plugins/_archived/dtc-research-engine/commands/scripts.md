Run the script-writer skill.

Locate research, personas, and angles files in the workspace. If $ARGUMENTS includes a product name, match against it. If a format is specified (ugc, vsl, preroll, tiktok, all), write scripts in that format. Default to UGC + one other format if unspecified.

Script the top 2-3 angles. For each angle and format:
- Write 2-3 hook variations
- Write the full script with stage directions and visual notes
- Time-check: ensure scripts are the right length for their format
- Use actual customer language from the research

Save as [product-slug]-scripts.md in the workspace.
