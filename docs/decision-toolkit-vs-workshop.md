# Decision: Both. Separated.

*The toolkit-vs-workshop question was a false binary. The answer is: split them into two entities that reinforce each other.*

*Modeled after Corey Haines: person (Swipe Files, Conversion Factory, content) + product (marketing-skills repo). Neither tries to be the other.*

---

## The Model

| | **Jackson / @ctrlswing** | **Channel 47** |
|--|--------------------------|----------------|
| **What it is** | The practitioner. Media buyer building real skills from real workflows. | The marketplace. Claude Code plugins built by practitioners. |
| **What it sells** | Teaching, content, coaching. The methodology. | The plugins. Install command, GitHub, docs. |
| **The plugin is...** | The proof ("here's what I built for my own accounts") | The product (install it, use it) |
| **Primary audience** | Marketers who want to build their own AI skills | Claude Code users who need marketing/ads skills |
| **Where it lives** | X (@ctrlswing), newsletter, ctrlswing.dev (planned) | channel47.dev |
| **Email capture** | "Build logs from a media buyer building AI skills" | "Get notified when new skills ship" |
| **Monetization** | Coaching/consulting, newsletter, workshops | Credibility + distribution for the person |

One Kit account. Source tags on every entry point. Same list, different doors.

## What Thursday Is

Not a product launch. Not a sales pitch.

**"Hi, I'm Jackson. This is what I'm doing."**

The presentation introduces the practitioner to the community. The plugin is proof. The methodology is the gift. The /start page captures the relationship.

**Signals to watch:**
- Do people ask about *their own* workflows? = methodology resonates
- Do people ask about the Google Ads tools? = product resonates
- Both are fine. The model supports both. They're just different doors into the same list.

## What's Resolved

- **The identity split**: CH47 = product, Jackson = person. Done.
- **The weekly positioning resets**: Stopped. The product doesn't need to carry the personal narrative. The person doesn't need to be a marketplace.
- **The naming**: "ads plugin" → "google-ads". Transparent, specific, expandable.
- **The email strategy**: One list, multiple entry points, source tags.
- **The site**: Stripped to essentials. Install command, GitHub, email. No manifesto, no hero narrative, no stats bar.
